# StudentHub

StudentHub is a modern student collaboration platform designed to help students learn, share knowledge and earn from their academic resources.

---

## Features

- Student Authentication
- Admin Dashboard
- Resource Marketplace
- Activity Timeline
- Responsive Dashboard
- Firebase Authentication
- Firestore Database
- Role-Based Access
