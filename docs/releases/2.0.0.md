# StudentHub 2.0.0 release notes

Prepared 2026-09-09 from 2.0.0-rc.1. The application version is `2.0.0`. This
document records release preparation, not a published release or a READY
declaration. Archive, commit, tag, push, and production rollout are pending.

## Included in V2

- Discover across community resources, solved questions, collections, quizzes,
  and flashcards.
- Learning Memory and Thuto recommendations with editable study plans.
- Community reputation, trusted curation, and knowledge collections.
- Notifications and integrated resource, planner, flashcard, and quiz workflows.
- Bounded community file queries and atomic generated quiz/deck saves.
- Mobile drawer keyboard focus correction, verified locally.

## Validation and remaining release work

Real-account private-data isolation and scoped moderation passed all 13 live
assertions. Populated QA passed text-chat send/edit/reaction flows, incoming
friend acceptance, notification state/deep links, and resource metadata,
favourites, filtering, and planner integration. See the
[authorization report](../v2-live-authorization-review.md),
[accessibility report](../v2-accessibility-mobile-review.md), and
[real-data QA report](../v2-real-data-qa.md).

`npm run check` passed for version 2.0.0 on 2026-09-09: lint, formatting,
syntax, 544 unit tests across 152 files, architecture tests, and production
build. This automated result does not clear the manual QA findings below.

New outgoing friend requests are still blocked: the service reads missing
`friends` and `friendRequests` documents before creating a request, but the
deployed rules deny those reads. Fix and retest this path before release
sign-off. Updating the version does not resolve or waive this blocker.

File-content preview remains unverified. The resource checks used metadata
fixtures; an external PDF sample failed to render in the review browser. The
drawer fix also awaits Hosting deployment and live verification.
